# Albedo for the Arch R launcher

[Albedo](https://github.com/mluizvitor/es-theme-albedo) is an EmulationStation
theme by **mluizvitor**, under the MIT License. This is its conversion for the
[Arch R](https://arch-r.io) launcher: the same tilted system cards, the system
name standing vertical and the art across the screen, with the original's
options (accent colour, font size, list background and more) under
Settings › Appearance › Theme options.

Systems Arch R has and the original does not (Modules, itch.io, BBC Micro,
Macintosh, Windows and others) got cards and backgrounds made in the same
style.

Install it from Settings › Appearance › Theme store.

---
